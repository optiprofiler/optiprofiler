# OptiProfiler 1.3.6

This is a maintenance release of the Python 1.x paper version. It contains one
correction and no new features.

## Correction since 1.3.5

- Name the saved feature when loading results. A load without `feature_name`
  titled the summary PDF and the last log line with the default feature,
  "plain", whatever feature the saved experiment used. The name is now read
  from the saved feature stamp, for example `linearly_transformed` for the
  stamp `linearly_transformed_rotated`; a stamp of another form, which can be
  set by the user, is shown as it is. A `feature_name` given to a load remains
  the label. Scores, stamps, folder names and saved archives do not change.

Summary PDFs written by earlier loads keep their old title; load the
experiment again to redraw them. With earlier versions, passing the
experiment's `feature_name` to the load call gives the right title.
