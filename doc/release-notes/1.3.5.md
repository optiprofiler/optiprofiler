# OptiProfiler 1.3.5

This is a maintenance release of the Python 1.x paper version. It retains the
existing solver interface and bundled problem-library architecture. It does
not include the development plugin architecture, EvalReport, or composed
Feature API planned for 2.0.

## Corrections since 1.3.4

- Preserve saved solver and problem-selection information when loading results;
  apply solver-dependent checks after loading, and honor explicit history-plot
  and score-only choices.
- Do not treat undefined/NaN required constraint evaluations as feasible.
  Correct constraint counting, equality projection, affine constraint
  handling, and floating-point custom-merit values.
- Correct significant-digit truncation and quantized-feature ground-truth
  bookkeeping for initial values, histories and returned-point assessment.
  Solver-returned coordinates are not rounded or replaced.
- Save numerical results before plotting; use atomic HDF5 replacement and
  collision-safe experiment directories. Avoid GUI figure managers and improve
  history-plot handling of extreme values and portable labels.
- Include the pinned S2MPJ and PyCUTEst adapter corrections and retain upstream
  S2MPJ license/attribution information in the Python distributions.

## Reproducibility and scope

The maintenance branch retains its exact problem-library Git submodule pins;
this release does not refresh the problem corpus or adopt development-provider
APIs. Record the package version, dependencies, problem selection, solver
settings and random seed with new experiments.

Loading an old experiment preserves its recorded data. In particular, an old
quantized experiment with inconsistent truth channels is not repaired by
redrawing its plots; rerun it when corrected numerical evidence is needed.
Only load archives from trusted sources: native Python objects in an HDF5
archive can use pickle and are not a safe interchange format for untrusted data.

Python 3.8 remains supported subject to compatible dependency versions. Optional
PyCUTEst requires a separately working CUTEst/PyCUTEst installation; source and
binary distributions do not install that native toolchain automatically.
